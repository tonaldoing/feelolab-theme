A light, accessible classic theme for small business sites: home built from sections, brand colors with guaranteed contrast, no jQuery.

== Description ==

FeeloLab is a classic theme for service businesses, shops and professionals. The home page is built from sections (hero, services, products, team, testimonials, FAQ, contact, map) that you turn on, reorder and edit from Appearance → Customize, with live preview.

* Brand colors with automatic WCAG AA contrast: text and buttons always stay readable, whatever colors you pick.
* Four bundled typefaces (served from the theme, no external requests) or your own .woff2 font.
* Block patterns for pages: stats, team, intro with buttons, logos, pricing and more.
* WooCommerce support: shop, product, cart and checkout styled with the brand colors.
* No jQuery, no frameworks, and CSS only for the blocks each page uses.
* Accessible: skip link, visible focus, landmarks and reduced motion support.

The theme works on its own. The companion plugin FeeloLab Core adds the content types (services, products, team, locations, testimonials, FAQ), business settings, contact form and schema. The theme uses them when the plugin is active and hides those sections when it is not.

The interface is written in Spanish and includes an English (en_US) translation.

== Installation ==

1. In your admin, go to Appearance → Themes → Add New Theme and search for FeeloLab, or upload the zip.
2. Activate the theme.
3. Go to Appearance → Customize to set your logo, colors, typography and home sections.

== Frequently Asked Questions ==

= Does the theme load anything from other sites? =

No, with one exception: if you add an address and turn on the map section, the page shows an embedded Google Maps map (see "External services" below). Fonts, icons and images are served from the theme.

= Can I reorder the home sections? =

Yes. Appearance → Customize → Home → Section order. Drag the sections and the preview updates live.

== External services ==

Google Maps: when the map section is on and there is an address, the theme embeds a map from https://www.google.com/maps with that address, and shows a link to open it in Google Maps. The visitor's browser sends the address and its own IP address to Google when the map loads.
